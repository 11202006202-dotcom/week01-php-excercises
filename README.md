## How to run with XAMPP

1. Copy the `week01-php-exercises` folder into:
   `C:\xampp\htdocs\`
2. Start **Apache** in XAMPP.
3. Open:
   `http://localhost/week01-php-exercises/exercise01/`
4. Change `exercise01` to `exercise02`, `exercise03`, etc.

The exercise sheet says to keep each exercise in a separate folder inside the XAMPP document root and run it through an HTTP address. It also requires fictional personal information and testing of unusual/invalid cases.
